# 05 · 语境阶梯 L0–L5 与反向 R1–R3

> **每次编译必读。** 本文件定义每一级"允许做 / 禁止做"的边界。
> Web 版的"语境滑块"就是本阶梯的连续化呈现；Skill 版以离散级别输出，两者语义必须一致。

---

## 阶梯总览

| 级别 | 名称 | 正文是否改动 | 损耗权重 | 主要动作 |
|---|---|---|---|---|
| `L0` | 原样 Verbatim | 否 | 0.00 | 照搬，作为 diff 基线 |
| `L1` | 注释轨 Annotated | **否** | 0.05 | 外挂注释层 |
| `L2` | 轻度显化 Softly Explicit | 极小 | 0.15 | 补指代、主语、对象、时间 |
| `L3` | 叙事显化 Narrative Explicit | 是 | 0.35 | 心理外化为动作与因果 |
| `L4` | 功能化 Functional | 重写 | 0.75 | 只留事实、诉求、边界、动作项 |
| `L5` | 机读化 Machine-Readable | 结构化 | 0.95 | 字段化，零歧义 |

---

## L0 · 原样 Verbatim

原文逐字。存在的意义只有一个：**作为 Diff 的左侧**，让用户看见每一级多出来了什么。
不做任何清洗、不修正错别字、不调整标点。

---

## L1 · 注释轨 Annotated

> "在包裹外面贴标签，而不是拆开包裹。"

**做什么**：正文一字不动，所有解释以注释形式外挂。输出形式为 `正文 + 注释列表`，注释用 span 锚定。

**允许**
- 补充意象来历、制度背景、称谓含义、习俗功能
- 标注潜台词方向（"此处为委婉拒绝"）
- 标注沉默/留白的作用

**禁止**
- ❌ 改动正文任何一个字（包括标点）
- ❌ 在注释里替读者下结论式评价（"这说明中国人很虚伪"）
- ❌ 把注释写成百科条目——每条注释 ≤ 40 字，只说**在这里起什么作用**

**输出形态**
```json
{
  "text": "（与 L0 完全一致）",
  "annotations": [
    { "span": {"start": 3, "end": 5}, "note": "折柳：送别习俗，'柳'谐音'留'，表挽留。" }
  ]
}
```

**适用**：追剧字幕伴侣、电子书浮层、语言学习、"帮我理解这段"。
**这是保真度最高的档位**——当用户珍惜原文时，默认给 L1 而不是 L3。

---

## L2 · 轻度显化 Softly Explicit

**做什么**：最小必要改写，只解决**字面层的不可解**。目标是让读者不误读，而不是让读者全懂。

**允许**
- 补零主语、零宾语、模糊指代（"那件事" → "上次说的那件事"）
- 补时间、地点、对象等被省略的必要成分
- 把无法直译的意象换成**一个短语级**的功能描述（"折柳" → "折下一枝柳，那是送别的意思"）
- 保留隐喻、保留委婉、保留语序美感

**禁止**
- ❌ 改变句子的情绪与分寸（委婉仍是委婉）
- ❌ 加入原文没有的心理描写
- ❌ 把成语展开成整句解释（那是 L3）
- ❌ **无证据地补主语**。无法确定时保留模糊，并在 `caveats` 注明

**适用**：字幕（受空间限制）、轻度本地化、保留文学性的翻译底稿。

---

## L3 · 叙事显化 Narrative Explicit

> 文化出海的主力档位。**保留情感张力，把内部心理与潜规则外化为因果逻辑和行动。**

**做什么**：不破坏文学美感，但把角色沉默、眼神背后的心理博弈，转化为符合低语境受众思维的**外部动机驱动 + 清晰因果链**。

**允许**
- 把心理动因写成**可见的动作、道具、空间关系**（首选）或简短内心独白（次选）
- 补一句前置说明来建立缺失的共识预设（**功能性，不是百科**）
- 重排因果顺序，让动机出现在行为之前
- 把位阶冲突外化为：谁先开口、谁被打断、谁坐哪、谁替谁圆场

**禁止**
- ❌ **把文化替换掉**（武侠改写成超级英雄、把"师门"改成"公司"）——这是本技能明确反对的粗暴本土化
- ❌ 把所有留白填满。留白是美学资产，只填**造成理解断裂**的那部分
- ❌ 加入原文人物不会有的价值判断
- ❌ 用旁白解释情绪（"他很愤怒"）代替外化（"他把杯子放回桌上，比刚才重了一点"）

**外化优先级**：动作 > 道具/空间 > 他人反应 > 简短内心独白 > 旁白解释
越往右越廉价，能用左边的就不用右边的。

**示例**
```
原：张总端起杯子，小李赶紧站起来。
L3：张总端起酒杯。小李几乎是弹起来的——在座最年轻的人不能坐着接这一杯。
    他双手把自己的杯子压到比张总的低了半寸，才敢碰上去。
```
（位阶没有靠称谓解释，靠"弹起来""压低半寸"外化了。）

## L4 · 功能化 Functional

> 商务、协作、谈判。**去修辞，留决策所需。**

**做什么**：提炼事实、诉求、态度、边界与动作项。彻底去水分。

**结构（固定四段）**
```
【结论】  一句话给 stance：同意 / 拒绝 / 有条件 / 搁置 / 试探 / 仅告知
【依据】  对方给出的理由（区分"真实理由"与"体面理由"）
【边界】  未说但已划出的限制（预算、时间、人、不可碰的点）
【动作】  你接下来该做什么 / 不该做什么
```

**允许**
- 直接写"这是拒绝"
- 区分"给出的理由"与"真实理由"（并标注这是推断）
- 指出对方**没说**的话（缺席即信息）

**禁止**
- ❌ 保留"回头""尽量""应该问题不大"这类未量化词
- ❌ 编造对方未表达的具体条件
- ❌ 把推断写成事实——推断必须带"推断/likely"标记与置信度

**⚠️ 强制附加项**：当 `audience.confrontation ≤ 0.30`（日/韩/中东/英国/拉美）时，L4 输出**必须**附一行：
> **对外回复建议**：不要照搬上面的措辞回复对方。给对方的版本见 R1/R2。

否则用户会把"方案不通过"直接转发出去，造成关系事故。

---

## L5 · 机读化 Machine-Readable

> 给 Agent、工单系统、CRM、自动化流程。**零歧义，可被程序消费。**

**必填字段**
```json
{
  "intent": "对方这次沟通想达成什么",
  "stance": "accept | reject | defer | conditional | probe | inform",
  "confidence": 0.0,
  "action_items": [{"owner": "", "action": "", "due": "ISO8601 或 null"}],
  "constraints": ["明确或隐含的限制"],
  "deadline": "ISO8601 或 null",
  "escalation_needed": true,
  "evidence": ["支撑 stance 判定的原文片段"]
}
```

**规则**
- `stance` 取值**只能**是枚举内的六个之一
- 所有时间必须 ISO 8601；"回头""改天"→ `null` + `constraints: ["未给出时间"]`
- `confidence < 0.6` 时 `escalation_needed` 必须为 `true`
- `evidence` 不能为空——无证据的 stance 判定不允许输出
- **禁止**在 L5 里出现修辞、语气词、解释性散文

**适用**：`audience: ai-agent` 强制走这一档。

# 反向阶梯 R1–R3 · 语境收敛

> 把低语境直球文本编译成得体的高语境表达。用户在说"我这话太直了""怎么说得委婉些""别得罪人"。

## R1 · 得体化 Softened

**做什么**：加缓冲、给台阶、留余地。**不改变实质内容**。

手法：
- 结论后置，先肯定对方投入（"这个方向我们认真看过了"）
- 把否定归因于客观约束而非对方能力（"今年的预算盘子已经定了"）
- 给一个可执行的替代动作（"如果 Q3 重启，我第一时间找你"）
- 把"不"换成"目前还不具备条件"，但**保持可识别**——不能委婉到对方读不出这是拒绝

**禁止**：❌ 委婉到实质态度消失。R1 的底线是**圈内人读得出这是拒绝**。

## R2 · 关系化 Relational

**做什么**：在 R1 基础上加入关系语法。

手法：
- 正确的称谓与敬语（需要知道对方职级/年资；不确定时**问用户**，不要猜）
- 开场致意与收尾寒暄
- 面子归属：把决定的责任分散（"我们内部讨论下来"），不让任何一方独自承担否定
- 人情记账（"这次麻烦你了，回头一定补上"）——**仅在用户确实打算兑现时才加**

**禁止**：❌ 代替用户做出他不打算兑现的承诺。

## R3 · 圈层化 In-group

**做什么**：使用目标圈层的黑话、梗与留白，让圈内人秒懂。

**⚠️ 风险最高的一档。** 用错黑话比说直话更伤——会暴露"外人在模仿"，反而拉远距离。

**只在同时满足以下条件时执行**：
1. 用户明确要求；
2. 目标圈层有明确定义（不是笼统的"年轻人"）；
3. 你对该圈层的当前用语有把握（黑话半衰期以月计）。

任一条不满足 → **停在 R2**，并在 `caveats` 写明原因。

---

## 级别选择速查

```
用户想干什么？
├─ 想读懂 ─────────────► L1（珍惜原文）/ L4（只要结论）
├─ 想做决策 ───────────► L4 + L5
├─ 想让外国读者看懂 ───► L3（默认）；阻抗 ≥75 时考虑重构而非改写
├─ 想喂给系统 ─────────► L5（强制）
├─ 想做字幕 ───────────► L2（空间受限）+ L1 注释浮层
├─ 想说得委婉 ─────────► R1（默认）/ R2（有明确关系结构时）
└─ 不确定 ─────────────► L4 + L1，两个都给
```
