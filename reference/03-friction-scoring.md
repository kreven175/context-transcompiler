# 03 · 文化阻抗评分与韵味损耗

> 本文件定义两个核心数值：**Friction（文化阻抗）** 与 **Loss / Fidelity（韵味损耗 / 保真度）**。
> 二者必须同时报告。只报 Friction 会诱导用户一路滑到 L5 并丢掉全部原作价值。

---

## 1. 为什么是两个数

```
        Friction ↓                                  Loss ↑
   L0 ──────────────────────────────────────────────────────► L5
   原样                                                    机读化
   100% 保真                                            0 歧义
   圈外人看不懂                                      圈内人觉得索然无味
```

用户真正要做的决策不是"降到最低"，而是**在自己的场景里选一个停点**：

| 场景 | 该优化什么 | 合理停点 |
|---|---|---|
| 商务决策 | Friction 最低 | L4 / L5，Loss 高无所谓 |
| 文化出海 | Friction 与 Loss 的乘积最小 | 通常 L3 |
| 阅读辅助 | Loss 必须接近 0 | L1（正文不动，只加注释） |
| Agent 管线 | 零歧义 | L5，强制 |

**报告时必须给一句取舍说明**，例如：
> 取 L3：阻抗从 72 降到 31，保真仍有 65。若再降到 L4，阻抗只再降 9 分，保真却掉到 24——不划算。

## 2. Friction Score（0–100）

### 2.1 五维原始分

```
Raw = P + S + M + H + E          # 上限 100
```

> Raw 只是中间量。最终 Friction 由 §2.3 的三条规则得出（层次拆分 / 单维极值 / 密度归一），
> 实现见 `scripts/probe.py::compute_friction`。文档与代码不一致时以代码为准并提 issue。

| 代码 | 维度 | 满分 | 测量对象 |
|---|---|---|---|
| `P` | 共识预设依赖 | 25 | 需要外部背景才能理解的命题密度 |
| `S` | 潜台词背离度 | 25 | 字面义与实际义的距离 × 出现频次 |
| `M` | 文化意象负载 | 20 | 不可直译的专有意象/典故密度 |
| `H` | 位阶与面子编码 | 15 | 关系结构是否承载关键信息 |
| `E` | 留白与省略率 | 15 | 必要信息被省略的比例 |

### 2.2 各维打分细则

**P · 共识预设依赖（0–25）**

| 分段 | 判据 |
|---|---|
| 0–5 | 无需任何背景；自足文本 |
| 6–12 | 1–2 处制度/习俗/专名需要背景，不影响主线 |
| 13–19 | 多处预设，或有 1 处**主线依赖**的预设（不懂就看不懂情节） |
| 20–25 | 整段建立在未言明的共同记忆上；缺背景则完全不可读 |

**S · 潜台词背离度（0–25）**

以最强的那一处为主、频次为辅：

| 分段 | 判据 |
|---|---|
| 0–5 | 字面即实意 |
| 6–12 | 有缓冲语但态度明确（"恐怕不行"） |
| 13–19 | 存在字面/实意背离，且方向可从文本推定 |
| 20–25 | 存在**方向相反**的背离（字面肯定、实为否定），或多处叠加 |

> "原则上同意，不过……回头再对齐" = 字面肯定 + 实为否定 + 多标记叠加 → 22–25。

**M · 文化意象负载（0–20）**

```
M ≈ min(20, 4 × 不可直译意象数 + 2 × 成语典故数)
```
当代圈层黑话按不可直译意象计（权重同传统意象）。同一意象重复出现只计一次，但若为全文核心意象（如整篇讲"江湖"），单项即可给 12–20。

**H · 位阶与面子编码（0–15）**

| 分段 | 判据 |
|---|---|
| 0–3 | 平等对话，称谓无位阶信息 |
| 4–8 | 有称谓位阶（X总/小X/老师），但不承载关键信息 |
| 9–12 | 位阶决定了**为什么有人不说话 / 为什么不能直接拒绝** |
| 13–15 | 全段冲突就是位阶冲突；去掉位阶信息则情节失去动力 |

**E · 留白与省略率（0–15）**

```
E ≈ min(15, 15 × ellipsis_rate × 1.2 + 沉默描写数 × 2)
```
`ellipsis_rate` 由 `probe.py` 估算（小句中无人称代词/专名的比例）。人工评估时按"需要读者自行补全的必要信息点数量"估计。

### 2.3 从 Raw 到 Friction：三条规则

Raw 是**文本自身的高语境浓度**，不等于传达成本。三条规则把它变成对特定受众的成本。

#### 规则一 · 语用层 vs 事实层（最重要）

**这是整套评分最关键的区分。**

| 层 | 维度 | 能不能靠"读空气"弥补 |
|---|---|---|
| **语用不透明** | S、M、H、E | **能**。高语境受众习惯在字面之外取信息，面对含蓄表达的成本确实更低。 |
| **事实缺失** | P | **不能**。日本读者再善于读空气，也不会知道"编制"是什么。 |

因此只有语用层随受众调制，P 维原样带入：

```
modulation = 0.55 + 0.45 × audience.explicitness
pragmatic  = S + M + H + E
Friction_breadth = min(100, pragmatic × modulation + P)
```

`P` 已在子分阶段按 `shared_ground` 折减过（文化类折减，制度类不折减，见 §2.2 与 `reference/04-audience-profiles.md` §4）。

**效果验证**：同一段含"编制""宅基地"的文本，对日本商务与德国商务受众都得到 **42 分**——因为障碍是双方都不具备的事实背景，而不是语用风格。早期版本把 P 一起调制、再用 `+0.15×P` 找补，既不可解释也补不够，已废弃。

| 受众 | explicitness | modulation | pragmatic=32, P=0 | pragmatic=10, P=14 |
|---|---|---|---|---|
| `zh-native` | 0.10 | 0.595 | 19 | 20 |
| `jp-business` | 0.10 | 0.595 | 19 | 20 |
| `us-genz` | 0.88 | 0.946 | 30 | 23 |
| `de-business` | 0.95 | 0.978 | 31 | 24 |
| `ai-agent` | 1.00 | 1.000 | 32 | 24 |

（上表是规则一单独作用的结果；实际分数还要过规则二。）

#### 规则二 · 加权单维极值

纯求和会稀释"一维顶格、其余为零"的高危文本。一段字面肯定、实为否定的话（S=25，其余为 0）比五个中等意象危险得多，但求和只有 25。

```
peak = max over dims of ( score/cap × 100 × PEAK_WEIGHT[dim] × (dim==P ? 1 : modulation) )
Friction = min(100, max(Friction_breadth, peak))
```

| 维度 | PEAK_WEIGHT | 理由 |
|---|---|---|
| P 共识预设 | 0.75 | 顶格＝缺少阅读前提，理解直接破裂 |
| S 潜台词 | 0.75 | 顶格＝读成相反的意思，后果最严重 |
| M 文化意象 | 0.55 | 顶格＝大量不可直译，但仍可部分靠上下文 |
| H 位阶面子 | 0.45 | 顶格＝关系信息丢失，情节仍大致可读 |
| E 留白省略 | 0.45 | 中文零主语极常见，顶格不应单独把分数推高 |

**效果验证**：PDF 里那段"出发点是好的……回头再对齐"，广度和只有 32，但 S 顶格 → 阻抗 73（高阻）。这才符合直觉——德国工程师会把它读成"方案通过了"。

#### 规则三 · 密度归一（只作用于 M 与 P）

M 和 P 是**计数型**子分。60 字里出现 3 个不可直译意象，远比 3000 字里出现 3 个难读。

```
density_factor = clamp(1.0, 2.0,  500 / max(120, char_count))
M ×= density_factor
P ×= density_factor
```

只上抬短密文本，不惩罚长文本（≥500 字时系数恒为 1.0）。
S 由最强单点驱动、E 本身就是比率，二者不参与归一。

### 2.4 一个完整算例

输入（75 字，武侠送别，受众 `us-genz`）：

| 步骤 | 结果 |
|---|---|
| 子分 | S=12, M=10→**20**（密度×2.0）, E=8, P=0, H=0 |
| pragmatic | 12+20+8 = 40 |
| modulation | 0.55 + 0.45×0.88 = **0.946** |
| 广度 | 40 × 0.946 + 0 = **37.8** |
| 单维极值 | M: 20/20×100×0.55×0.946 = **52.0** |
| **Friction** | max(37.8, 52.0) = **52** → `high` 高阻 |

### 2.5 分带

| 区间 | 带 | 含义 | 行动 |
|---|---|---|---|
| 0–24 | `low` 通行 | 可直接投放 | 无需处理 |
| 25–49 | `moderate` 轻阻 | 少量断点 | 局部注释/桥接 |
| 50–74 | `high` 高阻 | 系统性误读 | 需要 L3 以上改写 |
| 75–100 | `severe` 闭塞 | 不桥接等于不可读 | 改写而非注释；考虑重构叙事 |

## 3. Loss / Fidelity（0–100）

降维一定有代价。代价的大小取决于**降到哪一级**与**原文有多少不可直译的意象**。

```
ladder_weight = { L0: 0.00, L1: 0.05, L2: 0.15, L3: 0.35, L4: 0.75, L5: 0.95 }

Loss     = round( 100 × ladder_weight[L] × (0.4 + 0.6 × M / 20) )
Fidelity = 100 − Loss
```

直觉解读：
- **L1 几乎不损耗**（0.05 权重）——正文一字不动，只在旁边贴标签。这是"贴标签而非拆包裹"的档位。
- **L3 是分水岭**（0.35）——把心理外化为动作，损失了含蓄，但保住了情绪张力。
- **L4/L5 损耗剧烈**——这是刻意的：商务场景本来就不需要韵味。
- **M 越高，同一级别的损耗越大**——意象密集的文本降维更疼。M=0 时系数 0.4，M=20 时系数 1.0。

示例（Raw=80，M=16，受众 `de-business`）：

| 级别 | Friction | Loss | Fidelity | 评语 |
|---|---|---|---|---|
| L0 | 78 | 0 | 100 | 原样，看不懂 |
| L1 | 62 | 4 | 96 | 加注释，几乎不伤原文 |
| L2 | 52 | 13 | 87 | 补指代，语感略平 |
| L3 | 33 | 30 | 70 | **甜点** |
| L4 | 21 | 65 | 35 | 只剩信息 |
| L5 | 8 | 82 | 18 | 机器友好，人读无味 |

> L1 的 Friction 不是 0：注释能补上信息，但读者仍要跳出正文去读注释，沉浸感与理解流畅度有损耗。
> 经验折算：`Friction(L1) ≈ 0.8 × Friction(L0)`，`L2 ≈ 0.67`，`L3 ≈ 0.42`，`L4 ≈ 0.27`，`L5 ≈ 0.10`。

`probe.py --target-level` 会直接算好这组数，不必手算。

## 4. 断点密度（Hotspot Density）

给创作者的第二个实用指标：

```
density = 严重度 ≥ 3 的热点数 / (字符数 / 1000)
```

| density | 解读 |
|---|---|
| < 2 | 顺畅 |
| 2–5 | 需要局部桥接 |
| 5–10 | 读者每两三百字就会卡一次，**弃读风险高** |
| > 10 | 需要重构，而不是打补丁 |

这是"毒点/断点排查"报告的主指标——比总分更能说明"为什么海外读者看不下去"。

## 5. 手工评分速查（无法执行脚本时）

1. 通读，标出所有让你觉得"外人会卡住"的片段 → 这是 hotspots。
2. 数一数：不可直译意象几个？成语几个？→ 算 `M`。文本 < 250 字则 `M × 2`。
3. 有没有字面/实意背离？最强的一处多严重？→ 给 `S`。
4. 有没有不懂背景就看不懂的地方？几处？主线依赖吗？→ 给 `P`。文本 < 250 字则 `P × 2`。
5. 称谓和位阶承载信息吗？→ 给 `H`。
6. 有多少句需要你自己补主语/补前提？超过一半的部分才计入 → 给 `E`。
7. **规则一**：`(S+M+H+E) × (0.55 + 0.45×explicitness) + P` → 广度分。
8. **规则二**：算五维中加权极值最大的那一个（权重见 §2.3），取它与广度分的较大者 → Friction。
9. 按目标级别查 `ladder_weight` 算 Loss。
10. 在 `confidence.caveats` 写"未执行确定性预扫描，分数为人工估计"。

手工评分误差可达 ±15 分，只用于**同一文本改写前后的相对比较**，不要跨文本比。

## 6. 反向模式的度量：Abrasion 得罪风险

**Friction 不适用于反向模式。**

一段直白的中文发给日本客户，Friction 很低——对方完全看得懂。问题不是看不懂，是**看懂了会不高兴**。用阻抗去衡量这种场景，会给出"没问题，可以发"的错误结论。

因此反向模式（R1–R3）用另一个数：

```
Abrasion = round( 100 × directness_index × (1 − audience.confrontation) )
```

**`directness_index ∈ [0,1]`** 由直白度标记驱动（`scripts/lexicon/directness.json`）：

| 类别 | 例子 | 权重 |
|---|---|---|
| `negation` 直接否定 | 不行、不可能、做不了、拒绝、错了 | 0.5–1.0 |
| `ultimatum` 最后通牒 | 要么…要么、否则、到此为止 | 0.5–0.9 |
| `demand` 硬性要求 | 必须、立刻、之前给、给个准话 | 0.6–0.8 |
| `imperative` 归责 | 你们、你方、是你、你负责 | 0.3–0.8 |

```
weighted = Σ 命中标记的权重（按原形去重）
raw      = weighted / (1 + weighted)              # 饱和到 (0,1)
damp     = 1 / (1 + 0.45 × 缓冲语与面子语命中数)    # 有缓冲则直白度下降
directness_index = raw × damp
```

### 效果验证

同一段话："这个价格我们做不了，低于成本了。要么你们加钱，要么这单就算了。下周一之前给个准话。"

| 受众 | confrontation | Friction | **Abrasion** | 结论 |
|---|---|---|---|---|
| `jp-business` | 0.05 | 8 | **76** | 必须走 R2 收敛后再发 |
| `nl` | 0.95 | 13 | **4** | 直接发，对方觉得专业 |

**Friction 几乎一样，Abrasion 差 19 倍。** 这正是两个数必须分开的原因。

### 分带与动作

| Abrasion | 带 | 动作 |
|---|---|---|
| 0–19 | 安全 | 直接发 |
| 20–39 | 留意 | 加一句缓冲即可（R1 轻度） |
| 40–64 | 高危 | 走 R1，必须给台阶与替代动作 |
| 65–100 | 关系风险 | 走 R2，加称谓、分散责任、人情语法 |

`probe.py` 在 Abrasion ≥ 40 时自动写入 caveat。

## 7. 分数的诚实边界

- 这套评分是**可复现的启发式**，不是经过大样本验证的心理测量量表。对外表述时用"指数/指标"，不要说"科学测定"。
- 分数的价值在**相对比较**（改写前 vs 改写后、A 版 vs B 版、这一段 vs 那一段），不在绝对值。
- 受众参数是群体先验，不适用于判断具体某个人。涉及具体个人时降低置信度并在 `caveats` 注明。
- 若文本极短（< 40 字），密度类指标不稳定，应只报 hotspots 与 stance，不报总分，并注明"文本过短，未计算总分"。
