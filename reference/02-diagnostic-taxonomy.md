# 02 · 诊断分类学：六类语义探针

> **每次诊断必读。** 本文件定义热点（hotspot）的分类、识别标记、误读风险与低语境展开式。
> 每一个 `hotspots[]` 条目的 `class` 字段必须取自这六类之一。

---

## 判定总则

1. **先证据，后分类。** 必须能指回原文的具体 span。不能回指的判断不写进 `hotspots`，写进 `unstated_premises` 或干脆不写。
2. **一处可多类，取主类。** "张总说'年轻人有冲劲很难得'"同时是 `FACE` 和 `HIERARCHY`；取承载关键信息的那一类作 `class`，其余放 `secondary_classes`。
3. **严重度 1–5**：
   - `1` 轻微——读错不影响行动
   - `2` 影响语感——读错会觉得怪，但能继续
   - `3` 影响理解——读错会误判人物动机或事实
   - `4` 影响决策——读错会做出错误行动（把拒绝当同意）
   - `5` 关系性风险——读错会得罪人、毁掉合作或彻底看不下去
4. **严重度是对目标受众而言的。** 同一句话对 `zh-native` 是 1，对 `de-business` 可能是 4。

## PRESUPPOSITION · 共识预设

> 作者默认读者已经知道的事。**最隐蔽的一类**——因为它根本没有对应的词，是一个"空位"。

**承载什么**：历史事件、制度常识、家庭与亲属结构、节庆与仪轨、行业惯例、地域常识、教育经历共识。

**识别信号**（多为"缺失"信号，词典命中率低，需靠语义判断）：
- 出现专名、机构名、制度名却不加任何解释（"考公""编制""户口""宅基地""春运""高考""中考分流"）
- 亲属称谓精确到关系位（"表哥""堂姐""二舅""婆婆"→ 英语只有 cousin / mother-in-law，**关系信息在翻译中必然丢失**）
- 时间/节庆指称（"过年回家""清明""中元""本命年""七月半"）
- 行为无需动机说明（"他把红包塞回去了""她给领导添了茶"——为什么？文中不写）
- 数字与谐音负载（"六六六""四""八八八""五二零"）

**误读风险**：外部受众不会意识到自己缺信息，只会觉得**情节跳跃或人物行为无动机**——这是出海作品"看不下去"的首要原因，比生词更致命。

**展开式**：
```
原：过完年他就再没回过村里。
L2：过完春节他就再没回过村里。
L3：春节是中国一年里唯一一次全家必须团聚的节日；他连这一次都没有再回去过。
L1 注释：【春节：中国最重要的节日，返乡团聚被视为义务性的，缺席带有断绝意味。】
```

**桥接手法**：就近植入一句功能性说明（不是百科条目）；或把制度转成后果（"编制"→"一份国家发的、几乎不会失业的工作"）。

## SUBTEXT · 潜台词

> 字面义 ≠ 实际义。**商务场景价值最高的一类**，直接决定 `machine_readable.stance`。

**承载什么**：委婉拒绝、无限期搁置、条件性同意、反话、试探、责备、催促。

**识别信号**（词典命中率高，见 `scripts/lexicon/hedges.zh.json`）：

| 表层 | 实际 | 强度 |
|---|---|---|
| 再研究研究 / 再看看 / 回头再说 / 改天 | 拒绝或无限期搁置 | 高 |
| 原则上同意 / 出发点是好的 / 方向是对的 | 后面必有"但是"，整体为否 | 高 |
| 有一定难度 / 有点困难 / 恐怕 / 不太方便 | 拒绝（尤其日语 ちょっと難しい） | 高 |
| 我们内部先对齐 / 慢慢对齐 / 今天先不展开 | 本次会议已结束此议题，不会再开 | 高 |
| 需要走个流程 / 上面还要看一下 | 推给不存在的上级，软拒绝 | 中 |
| 尽量 / 争取 / 应该问题不大 | 不承诺 | 中 |
| 很有想法 / 有点意思 / 勇气可嘉 / 还年轻 | 否定，且带评价降级 | 中 |
| 你先忙 / 辛苦了 | 结束对话信号 | 中 |
| 呵呵 / 哦 / 嗯 | 不满、敷衍、拒绝继续 | 高（网络语境） |
| 都行 / 随你 / 看着办 / 无所谓 | 常为不满或测试，**不是真的都行** | 中高 |

日语补充：`検討させていただきます`（检讨一下）＝拒绝；`前向きに検討`（积极研究）＝拒绝；`善処します`（妥善处理）＝不处理；`結構です` 歧义（要/不要皆可，必须看语境）。
韩语补充：`생각해 볼게요`（我想想）＝婉拒；`괜찮아요` 歧义同上。

**误读风险**：**级别 4–5**。低语境受众会把"原则上同意"读成同意、把"再研究研究"读成还有机会，从而继续投入资源、错过替代方案、在错误的人身上反复跟进。

**展开式**：
```
原：你这个方案的出发点是好的，年轻人有冲劲很难得。不过里面涉及到的几个
    跨部门协作的细节，我们回头再找时间慢慢对齐一下，今天先不展开了。
L4：方案不通过。跨部门协作是给出的理由，但不是全部理由。不会另约时间讨论。
L5：{"stance":"reject","confidence":0.85,"action_items":[],"escalation_needed":true}
```

**判定纪律**：
- `stance` 只能取 `accept | reject | defer | conditional | probe | inform`
- 证据不足时用 `defer` + 低 `confidence`，**不要为了果断而误判**
- 必须在 `evidence` 里列出支撑该判定的原文片段

## FACE · 面子策略

> 谁的面子在台上、话是怎么给对方留退路的。

**承载什么**：给面子、留面子、驳面子、下不来台、给台阶、自贬、抬举、代人受过。

**识别信号**（见 `scripts/lexicon/face_power.zh.json`）：
- 直接面子词：面子、里子、情面、台阶、下不来台、给个面子、驳面子、抹不开
- 自贬抬人：不敢当、承让、哪里哪里、过奖、献丑、鄙人、在下、敝司、小店
- 抬举对方：赏光、赏脸、高抬贵手、劳驾、久仰、贵司、您
- 先扬后抑结构：肯定句 + "不过 / 只是 / 就是" + 否定（本身就是面子装置）
- 第三方转述："大家都觉得…""有同事反映…"（把批评去个人化，保全直接关系）
- 公开 vs 私下差异：当众说的和会后说的不是同一件事

**误读风险**：级别 3–4。低语境受众会把先扬后抑的"扬"当作真实评价，或把自贬当作真的能力不足；也会在公开场合直接反驳，造成不可逆的关系损伤。

**展开式**：
```
原：小李这次辛苦了，做得挺好的，就是有几个地方还可以再打磨打磨。
L4：工作不达标，需要返工。"辛苦了""挺好的"是当众说话的缓冲，不是评价。
L3（叙事轨）：他在全组面前先夸了小李两句，才说起那几个"可以再打磨"的地方。
     小李听懂了——在这个房间里，夸奖的长度和批评的严重程度成正比。
```

**桥接手法（创作者）**：把面子机制**外化为可见动作**——谁先开口、谁替谁打圆场、谁把话题岔开、谁在门口送客。西方读者读不懂"留面子"这个词，但读得懂"他替他把话接了过去"。

## HIERARCHY · 位阶与人情

> 谁能说话、谁先说话、谁欠谁、称谓里编码的权力。

**承载什么**：长幼尊卑、职级、师承、话语权分配、人情债与回报义务、座次与敬酒序列。

**识别信号**（强正则可检，见 lexicon）：
- 称谓模式：`X总`、`X董`、`X工`、`X老师`、`X师傅`、`X处`、`X科`、`老X`（年长/资深）、`小X`（年轻/下级）
- 敬语与谦辞：您、贵、敝、拙、犬子、家父、令尊
- 亲属化职场称呼：哥、姐、叔、老师（非教师义）
- 人情词：欠人情、还人情、回头请你吃饭、这事我记着、改天补上、给你添麻烦了
- 仪式性序列：敬酒、让座、送客、买单争夺、谁最后一个发言

**关键**：**`小李` vs `李总` 这一字之差就是全部的权力结构**，而英文里都是 "Li"。这是翻译中最大规模的静默信息丢失。

**误读风险**：级别 3–4。西方读者会问"他为什么不直接反驳老板""为什么她要替他买单""为什么这顿饭这么重要"——因为承载答案的称谓与序列在译文里消失了。

**展开式**：
```
原：小李，你先坐。张总还没到。
L2：小李（组里最年轻的下属），你先坐。张总（部门负责人）还没到。
L3：他叫他"小李"——组里资历最浅的那个。张总还没到，在座没有人先动筷子。
L1 注释：【称谓"小X"用于年轻或资历浅者，"X总"指向管理层；在座者等待职位最高者到场是默认礼节。】
```

**桥接手法（创作者）**：位阶不要靠称谓翻译（翻不出来），靠**空间与动作**外化——谁坐主位、谁先动筷、谁给谁倒水、谁的话被打断而没人抗议。

## MOTIF · 文化意象与典故

> 词背后带着历史沉淀或亚文化认知，直译等于没译。

**承载什么**：
- **传统意象**：江湖、折柳、明月、归乡、气、锅气、火候、留白、写意、侠、义气、恩怨、师门、走火入魔、因果报应、孝、光宗耀祖、门当户对、家丑不可外扬、落叶归根、衣锦还乡
- **成语典故**：卧薪尝胆、塞翁失马、对牛弹琴、画蛇添足、守株待兔（**直译成寓言会让读者误以为是本文情节**）
- **东亚邻域**：読空気（读空气）、建前/本音、義理/人情、修羅場、KY、눈치（眼力见）、한（恨）
- **当代圈层黑话**：内卷、躺平、破防、上岸、凡尔赛、摆烂、emo、抽象、发癫、city不city
- **中东/拉美**：wasta（关系门路）、inshallah（语境决定是承诺还是推脱）、sobremesa

**识别信号**：词典命中为主（`scripts/lexicon/motifs.zh.json` 分 `classical` / `idiom` / `east-asia` / `subculture` / `other` 五区）。词典未收录时，判据是：**该词在目标语言中没有等价概念，只能靠一句以上的解释来传达**。

**误读风险**：级别 2–4。
- 成语直译 → 读者以为是真实情节（"他卧薪尝胆"被读成"他睡在柴火上舔苦胆"）
- 当代黑话直译 → 完全失效且暴露翻译痕迹
- 传统意象直译 → 保留了画面但丢了含义（"折柳"→ breaking a willow branch，读者不知道那是送别）

**展开式（三选一，按层级）**：
```
L1 注释轨：折柳【古代送别习俗，"柳"谐音"留"，折柳枝相赠表示挽留与不舍】
L2 轻度：他折了一枝柳递过去——那是送别的意思。
L3 叙事：他从路边折下一枝柳，递到她手里。两个人都没说话。在这里，这个动作
        意味着送别，也意味着他不想让她走。
L4 功能：他做了一个表示送别与挽留的传统动作。
```

**纪律**：
- **不要杜撰典故出处。** 不确定来历时只描述功能（"这是一个表示送别的传统动作"），不要编造朝代、人物或文献。
- **不要过度注释。** 能靠审美与情绪直达的意象（枯山水的空、水墨的留白）不需要展开成说明文——见 `01-context-theory.md` §5.2。

## ELLIPSIS · 留白与省略

> 被省略掉的、以及被沉默承载的信息。

**承载什么**：零主语句、零宾语句、半截话、话题突转、沉默、只发一个表情、答非所问、重复对方的话。

**识别信号**：
- **零主语**：中文可以整段不出现主语。脚本用"从句中是否出现人称代词/专名"做启发式估算（`probe.py` 的 `ellipsis_rate`）。
- 半截话标记：`……`、`。。。`、破折号收尾、"那个……"、"反正……"、"不说了"、"算了"
- 默契代词："那件事"、"那个人"、"上次那个"、"你懂的"、"懂？"
- 沉默的描写："她没接话""屋里静了一会儿""他低头喝茶"
- 答非所问：问 A 答 B（本身就是拒绝或转移）
- 单字回应："嗯""哦""行"（在中文网络语境中是强信号）

**误读风险**：级别 2–4。
- 零主语 → 译文必须补一个主语，**补错就是事实错误**，这是机器翻译最常见的硬伤
- 沉默 → 低语境读者读成"没有信息"，而实际上沉默是本段最重的一句话
- 答非所问 → 读成人物思路跳跃，而非拒绝

**展开式**：
```
原：——那件事，办了吗？
    ——嗯。
    ——……行。
L2：——上次说的那件事，你办了吗？
    ——办了。
    ——（停顿）……那就好。
L3：他没有说是哪件事，也不需要说。对方只应了一声。他沉默了一下，才说"行"——
    那一下停顿里，是他在确认对方是不是真的办干净了。
L4：确认事项已完成；提问方对答复的完整性仍有保留。
```

**纪律**：**补主语必须有文本证据。** 无法确定时，在 `caveats` 里写明"原文零主语，L2 版本补入的主语为推断"，不要静默地替作者做决定。
