# 06 · 领域剧本

> 按输入类型加载对应小节。每个剧本给出：**优先探针、默认参数、专项检查表、输出重点**。

---

## A · 职场沟通（会议发言 / 内部邮件 / 群消息 / 绩效反馈）

**默认**：`audience = global-english`（用户是外籍同事时取对应档案）｜`ladder = L4`，附 `L1`
**优先探针**：`SUBTEXT` > `FACE` > `HIERARCHY` > `ELLIPSIS`

**专项检查表**
- [ ] 有没有"先扬后抑"结构？"扬"的长度是否与"抑"的严重度成正比？
- [ ] 有没有无限期搁置标记（回头/改天/慢慢/先不展开/内部对齐）？
- [ ] 说话人的职级高于听话人吗？（决定了委婉是**权力的礼貌**还是**下级的谨慎**）
- [ ] 是公开场合还是私下？公开场合的评价一律按"经过面子加工"处理
- [ ] 有没有"缺席的信息"——该表态的地方没表态、该给时间的地方没给时间？
- [ ] 第三方转述（"大家都觉得…"）是否在去个人化地传达批评？

**输出重点**：`stance` + 下一步动作。用户要的不是理解，是**知道该不该继续投入**。

---

## B · 跨国商务（邮件 / 报价 / 合同讨论 / 谈判纪要）

**默认**：按对方所在地取档案｜`ladder = L4 + L5`
**优先探针**：`SUBTEXT` > `HIERARCHY` > `PRESUPPOSITION`

**专项检查表**
- [ ] 日方：`ちょっと難しい` / `検討します` / `前向きに` / `善処` → 一律按拒绝处理，置信度 ≥0.8
- [ ] 韩方：`생각해 볼게요` / 敬语层级变化（降级＝关系降温）
- [ ] 中方：`原则上` / `走个流程` / `上面的意思` → 软拒绝或推诿
- [ ] 中东：`inshallah` 需看场合——可能是承诺，也可能是礼貌推脱；**标为歧义并要求确认**
- [ ] 印度：`yes` 常为"我听到了"而非"我同意"
- [ ] 拉美：热情语气 ≠ 承诺；无明确时间即无承诺
- [ ] 谁有决定权？邮件里出现的人是决策者还是传话人？
- [ ] 抄送名单的变化（加人/减人）本身是信号

**输出重点**：
1. `stance` + `confidence` + `evidence`
2. **真实理由 vs 体面理由**的区分
3. 若 `confrontation ≤ 0.30`：必须同时给 R1/R2 的对外回复草稿

## C · 影视剧本 / 分镜 / 短剧

**默认**：`audience = us-genz` 或发行地档案｜`ladder = L3`
**优先探针**：`PRESUPPOSITION` > `HIERARCHY` > `ELLIPSIS` > `MOTIF`

**专项检查表**
- [ ] **"为什么他不直接说？"** — 每一处人物本可直说却没说的地方，是否有可见的外部理由？
- [ ] **"为什么她突然不说话了？"** — 沉默是否被镜头/动作支撑，而不是只靠演员表情？
- [ ] 位阶是否靠称谓承载？（译制后必然丢失 → 必须改用空间与动作外化）
- [ ] 有没有"无动机行为"——角色做了一件事，动机藏在文化常识里？
- [ ] 家庭/宗族结构是否影响剧情？（cousin 问题：表哥/堂弟在英语里是同一个词）
- [ ] 转场是否依赖观众补全时间线？
- [ ] 饭桌戏：座次、敬酒顺序、买单争夺是否有视觉呈现？

**输出重点**：`creator_advice`，每条含 `where`（场次/页码）+ `suggestion`（加什么镜头/动作/道具）+ `preserves`（保住了什么）+ `cost`。
**外化优先用画面**，不要建议加旁白或解释性台词。

## D · 网文 / 小说出海

**默认**：`audience = us-genz`｜`ladder = L3`
**优先探针**：`MOTIF` > `PRESUPPOSITION` > `HIERARCHY`

**专项检查表**
- [ ] 世界观专名（修真等级、门派、功法、官职）——是否在首次出现时给了功能性锚点？
- [ ] **前三章断点密度** — 这是弃读的决定窗口。density > 5 即高危
- [ ] 成语/典故直译会不会被读成真实情节？
- [ ] 称谓系统（师尊/师兄/道友/前辈）是否有一致的译名方案？
- [ ] "爽点"是否依赖读者对本土社会结构的理解（如"打脸"依赖面子机制）？
- [ ] 数字与谐音梗是否可译？

**输出重点**：**前三章逐段断点密度曲线** + 术语表建议 + 首次出现锚点清单。
提醒：不要建议删掉世界观术语，建议的是**首现锚定**（第一次出现时用一句话建立功能，之后照用）。

## E · 字幕 / 短视频

**默认**：`audience` 按平台｜`ladder = L2`（正文）+ `L1`（浮层）
**优先探针**：`SUBTEXT` > `MOTIF` > `ELLIPSIS`

**专项约束**
- 字幕**有字数与停留时间上限**——不能靠加解释解决问题
- 因此策略是：L2 处理正文（最小必要显化）+ L1 注释走**文化卡片/弹幕浮层**
- 语气词、单字回应（"嗯""哦""呵呵"）必须转成有信息量的译文，不能省略
- 多模态可用时：结合语调与表情判定 `SUBTEXT`，并在 `evidence` 里注明依据是非文本信号

**输出重点**：逐条字幕的 L2 文本 + 需要浮层的时间点清单。

---

## F · 社交媒体 / 品牌文案

**默认**：按投放地档案｜`ladder = L3`
**优先探针**：`MOTIF`（尤其 subculture 分区）> `PRESUPPOSITION`

**专项检查表**
- [ ] 梗的半衰期——该梗还活着吗？跨地域还有效吗？
- [ ] 谐音/数字梗能否重构而非直译？
- [ ] 有没有在目标文化中触雷的意象（手势、颜色、数字、动物、宗教符号）？
- [ ] 自谦式表达会不会被读成产品不行？
- [ ] 集体主义话术（"我们一起""大家都在用"）在高个人主义市场是否会失效？

**输出重点**：逐条改写 + **风险清单**（触雷项单独列出，严重度 5）。

---

## G · 反向：给高语境受众的对外文案

用户在说"我们要发给日本客户""这个公告要发到东南亚"。

**默认**：`ladder = R1`（默认）或 `R2`（有明确关系结构时）
**优先检查**
- [ ] 直接否定是否已加缓冲且仍可被识别为否定？
- [ ] 责任是否被分散（"我们内部讨论下来"）而非归于个人？
- [ ] 称谓与敬语层级是否正确？不确定时**必须问用户**，不要猜职级
- [ ] 是否给了对方台阶与替代动作？
- [ ] 有没有代用户做出他不打算兑现的承诺？

**输出重点**：R 版正文 + **一行说明"哪些地方加了缓冲、为什么"**，让用户知道自己发出去的是什么。
