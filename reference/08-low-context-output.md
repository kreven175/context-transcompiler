# 08 · 低语境输出验收标准

> **每次产出 L2/L3/L4 正文后必读。** 前七份文件管「读懂原文」，这一份管「写出来的东西合不合格」。
> 诊断再准，如果输出本身仍是高语境写法，整个转译就没有发生——只是把留白从第一层挪到了第二层。

---

## 为什么需要这一关

转译最常见的失败不是漏掉了热点，而是**译者本人的语言习惯漏了进去**。中文母语者写出的「显化版」往往仍然意合、仍然话题优先、仍然把关键事实留在字面之外，自己读起来很清楚，因为自己本来就知道答案。

一个真实的反面例子（本技能早期样例 05 的 L3）：

> 她没有说父亲后来回去没有。她不需要说——**那件事家里人人都知道结局**，而她刚刚把我放进了同一个位置。

这句点明了「有一个人人皆知的结局」，却从头到尾没说那结局是什么。对圈内读者，这是漂亮的留白；对低语境读者，这是一个**被明确告知却拿不到的信息**，比直接不提更让人卡住。

诊断层发现了「你爸当年也是这么说的」是施压，编译层也写出了「她把我放进了同一个位置」——但**关键事实仍然缺席**。这就是输出侧失败。

---

## 一、验收清单

L2/L3/L4 的正文必须逐条通过。任何一条不过，回去改，不要交付。

- [ ] **指代闭合**：每个代词、每个「那件事 / 那个人 / 上次那个」都能在输出文本内部找到唯一指代。不能指向文本之外。
- [ ] **无悬空共识**：没有「大家都知道」「不用多说」「众所周知」式的表述，除非紧接着就说出那是什么。
- [ ] **施事明确**：每个句子能回答「是谁做的 / 谁在说」。确实无主语且不影响理解的，要能说清为什么不影响。
- [ ] **关系显式**：相邻句之间的因果、转折、递进有显式标记，不靠读者从语序里推。
- [ ] **量词落地**：没有未量化的时间与程度词（回头、改天、尽快、差不多、有点、不少）。要么落成具体值，要么写明「原文未给出」。
- [ ] **专名锚定**：文化专名、制度名、称谓系统首次出现时有一句功能性说明。
- [ ] **自足性**：不依赖任何未在文内交代的事实。读者不需要查任何东西。

## 二、外人复述测试（最后一关）

把输出交给一个对源文化零了解的人，让他用自己的话复述两件事：

1. **发生了什么**
2. **为什么会这样**

复述不出来的部分，就是还没转译完。注意第二问——很多输出能让人复述出情节，却说不清人物为什么那样做，那说明只做了字面显化，没做动因显化。

实际使用时，以「我现在只有这段文字，没有任何背景知识」的身份把输出重读一遍。读到任何一处需要调用外部知识才能继续的地方，标出来改掉。

## 三、汉语 → 低语境的六种结构转换

这些是**语言结构层面**的差异，与文化意象无关。即使一段话里没有任何文化专名，不做这些转换，输出读起来仍然是「翻译腔的高语境」。

### 1. 意合 → 形合

汉语靠语序和语义自然连接，句间关系留给读者补。英语、德语需要显式连接词。

```
原文： 他把那封信看了三遍，没说话，起身把窗户关上了。
```
中文读者自动补出因果链：信的内容 → 所以沉默 → 所以关窗（隔绝外界）。
低语境读者读到的是三个**并列动作**，没有因果，只觉得人物行为零散。

```
L3： 他把那封信看了三遍。读完第三遍，他还是一个字也没说，只是起身把窗关上了——
     像是要先把外面的一切挡在外面，才有力气想信里的事。
```
补的不是形容词，是**连接**。

### 2. 话题优先 → 施事优先

汉语把话题提到句首，施事可以消失。

```
原文： 这件事我已经跟他说了。      （话题「这件事」前置）
L2：   关于调岗，我已经跟张经理说过了。（施事、受事、所指全部落地）
```

### 3. 模糊时间与程度 → 具体值，或明示缺席

`回头`、`改天`、`尽快`、`差不多`、`有点`、`不少`、`过一阵`
→ 落成具体值；原文确实没给的，写明「原文未给出时间」。

**不要悄悄替作者补一个**。推断出来的值必须标注为推断。

### 4. 关系前置 → 结论前置

中文邮件与发言常是：寒暄 → 背景 → 铺垫 → 结论。低语境读者的注意力分配是**倒过来**的——他们默认最前面的就是最重要的，读到一半没看到结论会认为这封信没有重点。

L4 有固定四段结构（结论/依据/边界/动作）强制处理这一点。**L3 叙事轨同样适用**：不能让读者读完整段才知道这一场戏里发生了什么。

### 5. 集体归因 → 明确主体

`我们觉得`、`上面的意思`、`大家都认为`、`有同事反映`
→ 写明是谁。确实不知道的，明确标注「说话人未指明主体」，**并说明这种模糊本身是一种责任分散**——这一层信息对低语境读者是全新的。

### 6. 成语与四字格 → 功能描述

不翻译字面，写它**在这里起什么作用**。

```
原文： 他只能卧薪尝胆。
❌ 直译： He slept on firewood and tasted gall.      → 读者以为真有这个情节
❌ 替换： He had to bide his time.                    → 丢掉了「主动受苦以积蓄复仇」的强度
✅ 功能： 他只能忍下来——不是等待，是刻意让自己记住这份屈辱，直到有能力还回去。
```

## 四、解释性的三条标准

### 1. 功能，不是百科

解释回答「它在这里起什么作用」，不回答「它的来历是什么」。

```
❌ 折柳是中国古代的送别习俗，起源于汉代长安灞桥，因「柳」与「留」谐音……
✅ 他折了一枝柳递过去。在这里，这个动作的意思是：我知道留不住你，但我还是想留。
```

朝代、出处、源流，除非情节依赖它，否则一律不写。

### 2. 就近植入，不集中堆放

解释跟在它要解释的东西后面，不要攒成一段背景介绍。读者在遇到困惑的那一刻就要拿到答案，而不是在前情提要里预先被灌输。

**例外**：`L1 注释轨`本来就是外挂注释层，不受此限。

### 3. 解释到后果为止

只说「这是中国的习俗」没有完成解释。要说到**它如何约束了人物的选择**。

```
❌ 在中国，婚礼是家族事务。
✅ 在这个家里，婚礼不是两个人的事，是整个家族要一起出席的事。
   他不去，缺的不是一个座位，是全家在亲戚面前的交代。
```

读者需要的不是文化知识，是**因果**。

## 五、常见残留（自查时重点看）

| 残留形态 | 症状 | 改法 |
|---|---|---|
| 二级留白 | 点明「有件众所周知的事」却不说是什么 | 把事实写出来，或删掉这个指涉 |
| 成语搬运 | 输出里仍有未展开的四字格 | 按 §3.6 转成功能描述 |
| 并列堆叠 | 连续短句无连接词，读来像电报 | 按 §3.1 补因果与转折 |
| 情绪词代替外化 | 「他很愤怒」「她心里难受」 | 改为可见的动作、道具、他人反应 |
| 注释腔 | 正文里突然冒出一句百科解释 | 按 §4.1 改成功能性说明，或移到 L1 注释层 |
| 称谓直译 | 「小李」「张总」照搬拼音 | 位阶靠空间与动作外化，不靠称谓 |

## 六、与保真度的关系

这份清单**不是**要求把所有留白填平。

- `L1` 不受本清单约束——它的正文本来就一字不动。
- `L2` 只需通过「指代闭合」「施事明确」「量词落地」三条。
- `L3` 需要全部通过，但**美学留白可以保留**：没有造成理解断裂的沉默、节奏性的短句、不需要解释也能感受到的意象，都应该留着。本清单针对的是**造成断裂**的那部分。
- `L4`/`L5` 全部通过，且不保留任何留白。

判断标准：**读者能不能在不知道答案的情况下，自己走到答案面前。** 走得到，就是美学留白，留着；走不到，就是断裂，必须补。
