# 04 · 受众档案

> **每次转译必读。** `audience` 决定 Friction 的调制系数、转译口径与 `creator_advice` 的落点。
> **不得临场发明受众参数**，必须从本表（及其机读副本 `scripts/data/audiences.json`）中取值。

---

## 1. 两个正交参数

绝大多数工具把"语境高低"压成一个数，这是错的。本技能用两个独立参数：

| 参数 | 含义 | 影响什么 |
|---|---|---|
| `explicitness` 0–1 | **信息要不要写明白**。越高越要求把事实、前提、结论写在字面上。 | Friction 调制系数；L2/L3 补多少背景 |
| `confrontation` 0–1 | **负面意见能不能直说**。越高越能接受当面否定、辩论、直接批评。 | L4 商务轨的语气；反向 R1/R2 的缓冲量 |

**为什么必须分开**：英国在 `explicitness` 上偏高（合同条款写得清清楚楚），但 `confrontation` 极低（"quite interesting" 意思是不行，"with the greatest respect" 意思是你错了）。用单一维度建模英国，任何一头都会错。

第三个辅助参数：

| 参数 | 含义 |
|---|---|
| `shared_ground` 0–1 | 与中文圈共享多少共识预设。影响 `P` 维的额外修正（见 `03` §2.3）。 |

## 3. 使用规则

1. **用户点名了国家/群体** → 取最接近的档案。没有对应档案时取 `global-english`，并在 `caveats` 写明"该受众无专属档案，按国际英语通用处理"。
2. **用户给的是职业/场景而非地域**（如"海外发行方""审片人""潜在投资人"）→ 按场景选 `us-business` / `global-english`，并在 `meta.audience_note` 写明推断依据。
3. **多受众** → 以 `explicitness` 最高者算 Friction（最坏情况），但在 `creator_advice` 中标出哪些建议只对特定受众成立。
4. **个体 ≠ 均值**。用户说"我老板是德国人"时，档案只能作为先验；`confidence` 下调 0.1–0.2 并在 `caveats` 注明。

## 4. 参数如何影响输出

### `explicitness` 高（≥ 0.85）
- L4 商务轨：**结论前置**。第一句就给 stance，理由放后面。
- 所有 `PRESUPPOSITION` 热点都必须桥接，不能靠"读者自己会查"。
- 禁止在译文里保留"可能""也许""回头"这类未量化的时间/程度词，必须落成具体值或明确标注为不确定。

### `explicitness` 低（≤ 0.30）
- 不要把原文的含蓄全部拆开——对方本来就读得懂。
- 重点转向 `PRESUPPOSITION`（共享度低的那部分）而非 `SUBTEXT`。
- 常见用途是**反向模式**：把低语境文本收敛给这类受众。

### `confrontation` 高（≥ 0.80）
- L4 可以写"方案不通过"。不需要缓冲。
- 反向 R1 的缓冲量调到最小，否则会被读成犹豫不决。

### `confrontation` 低（≤ 0.30）
- L4 商务轨仍要给出明确 stance（用户需要知道真相），但**要在同一段里附一句"对外回复建议"**，让用户不至于把 L4 原文直接发出去。
- 这是最容易出事的组合：用户拿到"方案不通过"就直接转发给日本客户 → 关系事故。
- **英国受众尤其注意**：`explicitness 0.78 + confrontation 0.25`，要把事实写清楚，但否定必须包装。

### `shared_ground` 高（≥ 0.40）
- `P` 维得分按 `P × (1 − 0.6 × shared_ground)` 折减。
- 但**制度、时政、教育体系类预设不折减**——日韩受众共享汉字意象，不共享"考公""编制""中考分流"。

## 5. 自定义档案

用户有自己的受众画像时，允许扩展，但必须：
1. 写进 `scripts/data/audiences.json`（或运行时通过 `--audience-file` 传入）；
2. 三个参数全部给值；
3. 在 `meta.audience_note` 里说明来源（"用户提供"）。

模板：

```json
{
  "id": "custom-xxx",
  "label": "描述性名称",
  "explicitness": 0.0,
  "confrontation": 0.0,
  "shared_ground": 0.0,
  "notes": "来源与适用范围",
  "source": "user-provided"
}
```
